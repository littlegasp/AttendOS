# AttendOS

Attendance & Workforce Management — a role-based attendance web app with GPS-verified check-in/out.

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # type-check + lint + tests
npm run build      # static site in out/
npm run deploy     # build + upload to Cloudflare
```

Status and decisions: `docs/PROJECT.md`. Working rules: `CLAUDE.md`.
